# Professional Interactions

A scenario-based interactive learning prototype built with React and JavaScript.

## What it demonstrates

- Scenario-based online learning
- React and JavaScript frontend development
- Semantic HTML
- Responsive UI design
- Accessible keyboard and focus behaviour
- Accessible validation that does not rely on colour alone
- Decision-based feedback
- Code-to-Figma design documentation

## Interaction

The prototype follows a four-screen flow:

Intro → Scenario → Decisions → Feedback

The learner reviews a fictional professional scenario, makes decisions across four areas of conduct, then compares their judgement with suggested responses and the reasoning behind each one.

## Accessibility

- Semantic structure with logical heading order
- `fieldset` and `legend` for each decision question
- Keyboard-accessible controls using native buttons and radio inputs
- Focus moves to the new screen heading when the screen changes
- Validation messages identify unanswered questions in text and move focus to the first one
- Reduced-motion support
- Responsive layout with large touch targets
